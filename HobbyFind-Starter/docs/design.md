다음 정보를 기반으로 Airbnb 디자인 스타일을 참고한 웹서비스 디자인 가이드를 작성해줘.
[서비스 개요]
- 서비스명: HobbyQuest
- 서비스 타입: 웹서비스
- 이용 조건: 비로그인 사용자도 이용 가능
- 목적: 내가 만든/경험한 취미 활동을 수집하고 자랑하는 사이트
- 추가 기능 제안은 포함하지 말 것

- Airbnb 디자인 시스템, UI 톤앤매너, 인터랙션 스타일

[페이지 구성]
1. 루트페이지
 - Top Bar: 로고 / 카테고리 필터(운동형, 수집형, 예술형)
 - Hero 섹션: 사이트 소개 문구
 - 메인 콘텐츠: 그리드 형식으로 사용자 프로필 나열, 대분류(운동형·수집형·예술형) 필터 가능
 - 카테고리 필터 선택 시 → 해당 카테고리에 속하는 취미를 가진 사용자들만 모아 보여주는 카테고리별 전용 페이지
(운동형 페이지 / 수집형 페이지 / 예술형 페이지)

2. 카테고리별 페이지
 - 페이지 상단에 선택된 사용자명과 간단한 사용자 취미 프로필 소개 문구
 - 해당 카테고리에 속한 사용자 프로필만 그리드 형태로 나열

[디자인 가이드에 반드시 포함할 항목]
1. 디자인 시스템 개요 (Design System Overview)
 - 브랜드 아이덴티티, 전반적인 톤앤매너, UI 키 비주얼 가이드
2. TailwindCSS 색상 팔레트 (Color Palette for TailwindCSS)
 - 브랜드 컬러, 서브 컬러, 포인트 컬러
 - 배경, 텍스트, 버튼, 경계선 등 색상 변수 정의
3. 페이지 구현 가이드 (Page Implementations)
 - 각 페이지별 핵심 UI 요소와 레이아웃 규칙
 - Hero 섹션, 카드형 콘텐츠, 필터 UI, 내비게이션 가이드라인
4. 레이아웃 컴포넌트 (Layout Components)
 - 헤더(Top Bar), 푸터, 그리드 레이아웃, 카드 컴포넌트, 필터/검색 UI
 - 반응형 및 재사용 가능성 고려
5. 상호작용 패턴 (Interaction Patterns)
 - 버튼, 필터 선택, 카드 호버/클릭, 페이지 전환 애니메이션
 - 모바일·데스크톱 환경에서의 동작 차이
6. 반응형 브레이크포인트 (Breakpoints) 

 TailwindCSS 기준 sm / md / lg / xl / 2xl 해상도별 레이아웃 변화
 - 모바일, 태블릿, 데스크톱 UI 가이드
[작성 스타일]
- 심플하고 직관적인 톤앤매너 반영
- TailwindCSS 클래스 예시 포함
- 표와 코드 블록을 적절히 활용
- 실제 디자이너·개발자가 참고할 수 있는 수준의 구체성
