## 🎯 프로젝트 개요

- HobbyFind는 사용자가 운동형, 지능형, 예술형이라는 3가지 대분류를 기준으로 다양한 취미를 탐색하는 웹 기반 취미 추천 플랫폼입니다.


## 🛠 기술 스택

### Frontend
- Next.js, React, TypeScript, Tailwind CSS, Shadcn/ui, Framer Motion

### Development Tools
- ESLint, PostCSS, Turbopack
